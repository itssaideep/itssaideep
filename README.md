## Featured projects

### SecureMesh — Bayesian AI Attacker–Defender IoT Security Testbed
`Python` `Docker` `Reinforcement Learning` `Bayesian Game Theory` `ESP32` `ESP8266`

A distributed IoT security testbed for studying adaptive interactions between attackers and defenders. The platform supports controlled multi-node experiments, Bayesian decision-making from observed behaviour, and evaluation of response time, availability, recovery, and resilience.

### Zero-Day Intrusion Detection System
`Python` `Machine Learning` `Reinforcement Learning` `Unsupervised Learning`

An unsupervised intrusion-detection approach for previously unseen attack behaviour. The system achieved **92.6% recall on known attacks** and **80% detection on unseen zero-day families** by combining network- and host-level signals in a dual-layer IDS architecture.

The project also investigates reinforcement-learning-based cyber defense, modelling how defensive actions can adapt to changing attacker behaviour.

### LoRa-Based AI Communication System
`Python` `Ollama` `Meshtastic` `LoRa` `ESP32` `M5Stack`

An AI-enabled, low-bandwidth communication system connecting a locally hosted Ollama model to a Meshtastic LoRa network. Requests can be generated at one endpoint and transmitted to remote embedded devices across bandwidth-constrained links.

### High-Availability Infrastructure Monitoring Platform
`Python` `Prometheus` `Grafana` `HAProxy` `Ansible` `Linux`

A distributed monitoring platform providing resilient observability across Linux, PostgreSQL, Proxmox, and SNMP targets. Deployment is automated with Ansible and Docker, while Prometheus, Grafana, HAProxy, and Alertmanager provide monitoring, visualization, routing, and alerting.
